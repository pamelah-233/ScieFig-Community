# Contributing to ScieFig

ScieFig's original application code is licensed under **AGPL-3.0-only**.
Contributions must be offered under that license or a compatible license that
the maintainers explicitly accept. You retain copyright to your contributions;
this project does not require copyright assignment.

Before opening a pull request:

1. Describe the concrete problem and the affected workflow.
2. Reuse existing canvas, measurement, calibration, and export implementations.
3. Run tests for the changed behavior and directly affected state transitions.
   Avoid unrelated refactoring and unnecessary full regression runs.
4. Provide reproducible steps and synthetic fixtures. Do not upload private
   research images, personal information, access tokens, or signing keys.
5. Identify third-party code, data, or models and include their source, license,
   attribution, and modification history. A link alone does not grant permission.

By submitting a contribution you certify that you wrote it, or otherwise have
the right to submit it under the stated license, and that third-party notices
have been preserved. Add a `Signed-off-by: <your name or established identity>`
line to your commit message to record this certification. No legal name or
private contact address needs to be published in an issue.

policy does not grant the maintainer permission to relicense other contributors'
work under a proprietary license; that would require separate permission.
