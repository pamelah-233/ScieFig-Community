# Windows 1.2.5 暂定更新

以下为当前开发记录，发布前仍会调整。

- 各模块的主画布在空白时保持居中，导入图像或生成图表后自动 Fit。只有缩放后内容超出视口时，超出的方向才可以滚动。缩回到完整可见或点击 Fit 后，滚动范围归零。
- 荧光模块的 RGB 图像支持在拆分前整图调节显示范围、亮度、对比度和黑白点。调整保留原图色相，可预览、导出，并在选择“调整后图像”时作为检测输入；定量强度仍使用原始数据。
- 优化右侧栏收起和展开动画，过渡期间保持控件排版稳定，减少重复布局和画布刷新。
- Browser 新增“添加到 WB 图片”入口，可将选中的原始图片批量加入 WB，继续裁剪和编辑。
- 明场“预处理／分割”和 IHC“导入”增加图像调整工具，支持显示范围、亮度、对比度、黑白点、降噪、白平衡和原图对比。测量时可明确选择原始图像或调整后图像；支持导出当前调整效果、未调整原图或分析叠加图，项目保存后保留调整设置。
- 明场和 IHC 增加可调强度的照明不均／光晕校正，估计背景照明场后进行校正。启用时自动选用调整后的分析输入，校正结果贯穿预览、分析和导出；已过曝丢失的细节无法恢复。
- 荧光、IHC 和明场移除流程模式选择。荧光导入后进入图像调整，IHC 和明场默认自动分析。明场 H&E 面积测量保留检测灵敏度、小区域过滤和批次阈值锁定，IHC 自动测量后可通过阳性、阴性示例校准阈值。移除旧手动分割入口及未参与 H-score 计算的阈值控件。旧项目的测量结果仍可查看。
- IHC 测量加入低、中、高三档检测灵敏度滑块，支持整图、ROI 和批量分析。批次阈值锁定后可重设，再按当前灵敏度建立新的共用阈值。
