# Windows 1.2.5

正式更新提示和 macOS ND2 读取修复归入 [已发布的 1.2.4](UPDATES_1.2.4.md)。Windows 开发版也已同步 ND2 解码兼容修复，并用现代与旧版 ND2 真图核对像素。

## 画布和工作流

- 各模块共用的主画布在空白时居中。导入图片或生成图表后自动 Fit，画面完整可见时无法滚动。放大到内容超出视口后，只有超出的方向可以滚动。缩回或点击 Fit 时恢复完整视图。
- 右栏收起和展开时减少重复布局和画布刷新，让动画更平滑，并维持过渡期间的控件排版。
- 图片浏览器新增「添加到 WB 图片」，支持将选中的原始图片批量送入 WB，继续裁剪和编辑。

## 图像调整和测量

- 荧光 RGB 图像在拆分前即可整图调节显示范围、亮度、对比度和黑白点。调整保留色相，可预览、导出，也可作为检测输入。定量强度取自原始数据。
- 明场「预处理／分割」和 IHC「导入」增加显示范围、亮度、对比度、黑白点、降噪、白平衡和原图对比。测量可选择原始图像或调整后图像。支持导出调整后图、原图和分析叠加图，项目会保存图像调整设置。
- 明场和 IHC 的照明不均／光晕校正可调强度，结果用于预览、分析和导出。启用时自动选用调整后的分析输入。修复一张图做过照度与白平衡后切图触发 `KeyError: 'gains'` 的问题，旧项目缺少照度参数时可重开并重新计算参数。照度算法的效果优化暂缓。
- 荧光、IHC 和明场各自改为单一工作流，移除模式选择、旧手动分割入口及无效阈值控件。明场保留 H&E 分割灵敏度、小区域过滤和批次阈值锁定。IHC 自动测量可用阳性、阴性示例校准阈值。旧项目的测量结果仍可查看。
- IHC 加入低、中、高三档检测灵敏度滑块，支持整图、手画 ROI 和批量分析。锁定的批次阈值可重设，再按当前灵敏度建立新的共用阈值。

## 测量默认模型

| 功能 | 当前默认 |
| --- | --- |
| H&E 肌纤维 | 通用纤维分割，组织边界适配列第二 |
| H&E 核计数 | 浅小核补查，默认面积上限 500 px² |
| 明场细胞尺寸 | 通用细胞轮廓 |
| 明场肌管 | 长肌管边界适配 |
| 荧光 DAPI 核计数 | 局部对比分水岭，核直径 9 px，核面积 8–300 px² |
| 荧光细胞面积 | 通用细胞分割，Laminin 膜轮廓适配列第二 |
| 荧光点计数 | 点状信号检测（LoG），框选样本计数仍从阈值计数进入 |
| 荧光肌管 | 通用肌管轮廓，现有单一模型 |

旧项目会恢复已保存的模型和参数。首轮对比覆盖 8 项功能，每项 10 张真图，含 H&E 参数复测共完成 280 次计算。DAPI 后续用当前组织图及同批另外 9 张原生 CZI 复核了小核默认值。排序依据轮廓叠加和漏检、误检的目视复核。

## 框选和目标绑定

- 荧光单通道预览点选黑点或白点时，画布先切到按钮所属通道。测量黑平衡的「仅所选通道」应用于实际目标，逐通道校正可同时保留。跨分图的框选或标线会被拒绝，换图时清理旧手势和 AI 测量 ROI。
- 明场和 IHC 切到叠加图时取消未完成的黑白点取样。换图时清理旧 ROI 和比例尺拖拽。
- WB 裁剪只接受与当前原图或所选条带相交的区域。重新渲染时清理未完成的框选。浏览器比例尺的切图取消机制已用真图复核。

## 验证和待复测

- 框选与目标绑定有 35 项相关回归测试通过，已从桌面开发版用真实 CZI、H&E、IHC 和 blot 图复核。
- 修复并行导入和计算期间另存为时有效任务被误判过期的问题。明场、IHC 和荧光同时各导入 20、50、100 张均完整入库。三模块同时实算时，保存的项目可重开，三个结果均正常提交到各自的目标图像。
- 修正压力脚本对 Qt 延迟销毁事件的处理。30 分钟实图复测完成 47 轮，关项目后的私有内存由第 3 轮的 543.7 MiB 增至第 45 轮的 552.3 MiB。明场重用同一测量的叠加图，荧光通道列表刷新后统一更新测量状态。整合后三轮真图并发的 Qt 心跳额外延迟 P95 为 166.8–191.2 毫秒。
- Windows 改为正常退出，关窗时等待后台工作收尾。空白启动、打开真实项目、WB 示例和真实 IHC 计算中关窗的原生退出复测均通过，故障日志为空。
- 按累计 60 分钟验收。两段实图压力复测共完成 144 轮、86 分 36 秒，其中整合版完成 97 轮。整合版关项目后的私有内存为 517.6–557.8 MiB，各轮心跳 P95 的中位数为 148 毫秒，97 轮中 2 轮超过 200 毫秒排查线，最大额外延迟 1.34 秒。故障日志为空。测试方法见 [Windows 压力测试方案](WINDOWS_STRESS_TEST.md)。
