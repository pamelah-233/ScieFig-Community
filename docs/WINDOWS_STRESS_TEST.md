# ScieFig Windows 压力测试方案

测试对象是桌面「ScieFig 开发版」对应的 Windows 程序。每次记下 EXE 路径与修改时间、CPU、内存、显卡和驱动版本、Qt 显示缩放、模型设备、输入文件数量及解码后尺寸。用真实图像与独立测试项目，报告和导出写到新的目录。涉及文件损坏、磁盘写满和强制退出的场景在隔离环境里执行。

## 优先验证的并发链路

1. 明场导入两张真实 H&E TIFF，可选同名异目录。图 A 开启照明校正，改强度，做白平衡。切到图 B，确认复选框和强度跟随当前图。打开、关闭、再次打开校正，切回 A，核对两张图各自的参数和预览。IHC 用两张真实 DAB 图走同样的步骤。检查 `KeyError: 'gains'`、异常弹窗和事件日志。
2. 先分别单跑明场 H&E 面积和 IHC DAB 测量，保存输入版本、ROI、参数、阈值和输出。保持相同输入，先发起 IHC 测量，再发起明场测量，同时启动荧光多图导入。记录三个后台任务的执行起止时间。至少有两个计算实际重叠。三任务没有同时执行的轮次需单独标记。
3. 在等待计算期间切换 IHC、明场、荧光、Browser 和排版。缩放、Fit、展开和收起侧栏，编辑与任务无关的图片。核对当前页面不会被后台任务切走，每个成功结果的图像 UID、ROI、预处理和测量参数均与发起时一致。有效结果与各自的单跑基线一致，离散计数、掩膜和阈值逐项对照，同设备下浮点统计按相应算法的数值容差比较。
4. 用另一轮专测过期结果。在同一任务运行时切换该模块的测量目标、改 ROI 或调整输入，再切换整个项目。记录哪些改变按当前产品约定会让任务过期。过期任务应明确结束，不写进旧图、新图或新项目。另一模块未改输入的任务应照常完成。重复点击同一分析入口时核对只提交一个任务。
5. 打开结果图、导出调整后图和统计，保存并重开 `.sfig`。对照分析实际使用的像素、当前导出图、记录的参数与重开结果。保存后再开始下一轮，避免把上轮任务或结果带进来。

## 工况矩阵

| 工况 | 输入和操作 | 验收重点 |
| --- | --- | --- |
| 单模块基线 | 明场 H&E、IHC DAB、荧光单通道和多通道各一组。分别做全图与手画 ROI，走正常导入、分析、导出入口 | 记录时间、像素与数值结果，作为并发对照 |
| 跨模块计算 | 明场、IHC 同时跑测量，荧光并行导入。负载升一级后把荧光导入替换为真实 DAPI 计数或阈值分割，加入同设备模型任务 | 实际重叠时长、切页响应、结果归属、重复提交、队列回落 |
| 批量与格式混合 | 每模块先用 20 张，再逐级增到 50 和 100 张。混合真实 8/16 位 TIFF、OME-TIFF、CZI、JPEG 或 PNG，以及重复文件名、中文路径和项目重开后的图片 | 图像与通道数量、位深、解码峰值、部分失败后的剩余任务、结果逐图匹配 |
| 编辑与画布 | 后台计算时在空画布和有图画布反复 Fit、放大、缩小，拖 ROI、调白平衡、预览原图、切页、收放右栏。前台补测 Browser 到 WB、WB 裁剪、qPCR 导入计算、排版导出 | 视图和侧栏位置、字体排版、交互响应、模块流转、结果串图检查 |
| 保存、导出与退出 | 并发时保存项目副本、导出图像或统计。分别在计算中、已保存后关闭。用实际 EXE 测两轮启动和退出 | 项目可重开、输出完整、退出后任务和工作进程归零。保存时尚未提交的结果按当时状态核对 |
| 故障和恢复 | 分轮注入坏图、测试副本移走、写入受限、磁盘不足、GPU worker 退出。另用隔离配置模拟异常关闭后恢复，并测试只保存照度开关、缺少 `gains` 的旧项目副本 | 提示可定位，失败任务退出忙状态，其他模块继续运行。恢复到最近一次可读快照，坏输出不得覆盖已有有效输出。旧校正参数缺失时仍可打开项目、切图并重新启用校正 |
| 长稳与设备压力 | 30 分钟快速压力，随后 2 小时发布前长稳。固定输入规模反复导入、计算、编辑、导出、关项目。CPU 和 GPU 分开记录，GPU 档补测多个模型任务争用 | 对照预热后的内存、显存、句柄、临时盘和空闲时回落，找连续增长、任务超时和性能退化 |

## 判定与记录

- **硬性失败**包括崩溃、应用异常、任务超时或持续忙、错误结果进入其他模块或图像、旧回调污染新项目、已保存项目无法重开、静默丢数据。出现一次即保留复现材料并标记失败。没有测到实际重叠的场次不能计入并发通过。
- **性能初始门槛**建议在同机同数据预热后使用。记录空闲、单跑和并发三档的耗时、任务尾部延迟和 Qt 事件延迟。常规规模以 Qt 50 ms 心跳的 P95 额外延迟 200 ms、单次额外延迟 2 秒作为首轮排查线。固定规模第 3 轮后，关项目、等待 30 秒再测空闲内存和句柄。若后续持续上升且内存累计增长超过 15% 或 300 MiB 中较大者，按泄漏嫌疑复核。用可见窗口和实际 EXE 复测长卡顿、绘制及退出行为。
- 保存操作序列、任务起止与退出状态、活动模块和目标 UID、预处理参数、两份输出的差异、错误日志和必要截图。每项标注通过、失败或未执行。故障注入造成的预期提示单独记录。

## 自动化入口

`tests/run_windows_overlap_stress.py` 使用本机开发版的嵌入模块及 `.local-runtime/bundled-dev-imports.py`，在隔离配置的离屏 Qt 窗口跑真实计算。它覆盖两图切换的 `gains` 回归、缩放与 Fit、IHC 和明场 ROI 计算、并行荧光导入及编辑、任务运行区间、分析和导出像素一致性、保存与重开。每轮记录到 `events.jsonl`，并保留两张 PNG 和 `.sfig`。失败时保存终端输出，原生异常或超时堆栈写入 `faults.log`。可见窗口、GPU、故障注入和长稳需另按矩阵执行。

在 `D:\ScieFig dev` 的 PowerShell Core 中运行，替换素材路径。输出目录应为新的测试目录。

```powershell
$report = Join-Path $env:TEMP ('ScieFig-overlap-' + [guid]::NewGuid().ToString('N'))
& '.local-runtime/python314/python.exe' 'tests/run_windows_overlap_stress.py' `
  --brightfield 'E:/test/HE/A.tif' 'E:/test/HE/B.tif' `
  --ihc 'E:/test/IHC/A.jpg' 'E:/test/IHC/B.jpg' `
  --fluoro 'E:/test/Fluoro/A.czi' 'E:/test/Fluoro/B.czi' `
  --rounds 3 --timeout 180 --output $report
```

串行基线加 `--serial`，全图基线再加 `--whole-image`。快速压力和长稳分别把 `--rounds 3` 换成 `--duration-minutes 30` 和 `--duration-minutes 120`，每次使用新的输出目录。长稳只保留首轮和最新一轮的图像及项目，每轮事件保留。默认每 5 轮关项目并等待 30 秒，采样私有内存、句柄数和临时目录大小。
