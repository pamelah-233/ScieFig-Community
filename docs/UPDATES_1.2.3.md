# 1.2.3 待发布更新

开发版已汇总至 `1.2.3-dev`；未发布新安装包，独立安装版不变。

- 上传源码前复核：后台使用实际开发版冻结模块检查 WB、荧光、IHC、明场、qPCR、浏览、排版及风格流程，复核项目保存／重载、导出及中英文布局。修复顶部工具栏在窄窗口被挤压的问题，空间不足时分行显示；补齐开发版中的主窗口与风格页模块，避免源码已有修订未进入 EXE。
- 多标记测量不再默认使用固定阈值 100：先填写原始强度阈值，或按已纳入细胞的通道均值估计 Otsu 起点；恒定信号要求手动设定，估计值不视为经验证的生物学阳性阈值。自动 A/B 每次计算按实际表型确定，手动选择保持明确；单一表型不显示没有意义的标签置换 p 值。
- 修复浮点 RGB 各颜色独立拉伸导致色相变化、RGBA 透明区域参与定量的问题。RGB 拆分仅分离显示颜色样本，不能从合成图恢复独立 marker；黄、白、灰等混合颜色的限制在入口提示。
- 可选“保守弱核补检”保留原始核分割，并用局部对比度增强候选补充弱核；可能增加误检，需人工复核。核分割完成后，多标记任务自动跟随新结果。
- 修复非 A 类细胞错误显示最近 B 连线和导出目标 ID 的问题。核筛选与已保存掩膜读取减少重复整图扫描；750 个对象示例的几何准备约 2.15→0.38 秒，筛选约 0.45→0.055 秒，仅为后处理阶段耗时。
- 补充 36 个本地独立视野的全流程验证，本地累计 38 个视野；包含独立单通道配对导出和原生 CZI，保留原始像素与标定。432 项逐细胞原始均值核对一致；没有本地人工真值，不报告识别准确率。后处理优化前后 36 个视野的掩膜一致；进一步弱核参数试验未表现出稳定收益，未加入开发版。

- 空间分析修复旧 `Combined intensity` 名称残留到拆分通道的问题，默认恢复通道名并允许手动改为 CD68 等 marker 名称。修改 marker 勾选、名称、阈值、核来源及其它分析参数后，明确提示重新计算，隐藏不匹配的旧列表与叠加并禁止将其作为当前结果导出；旧测量保留在历史中。显示开关仅影响显隐，不改变参与计算的 marker。

- 荧光与明场测量入口按用途重新命名，中英文同步；按钮提供悬停说明，所选功能的简短说明放在可滚动参数区。入口按钮等高换行，保留双列，检查小窗口与 150% 缩放。
- 空间分析增加同屏联动结果区：宽窗口图像与结果并排，窄窗口结果位于图像下方；常驻表型统计、细胞／邻域列表、距离分布及点选详情。保留完整五类结果和六份 CSV。不同表型的轮廓、同屏列表和完整结果表使用一致颜色；四 marker 的 16 表型颜色区分已检查，被排除对象使用灰色。首次计算优先使用实际出现的表型，避免默认空组合。
- WB 增加绝对值／归一化显示切换，默认显示扣背景积分灰度；画布、结果表与预览图同步，切换不重新计算。归一化内参为 1 属正常计算行为。
- WB 应用 Crop 后直接显示多条带对齐预览，可返回源图继续裁剪；完整图的多个裁剪区域与独立条带使用一致的测量来源、顺序和内参选择。修正裁剪区域未逐条测量、统计默认误取内参等流程问题，保留撤销／重做和合成 WB Demo。
- 本阶段暂停进一步模型及分割参数调优，保留当前参考设置与可选弱核补检；未训练新权重。

- 针对真实组织荧光图补充核分割参考参数：核专用 Cellpose、直径 25 px、面积 8–5000 px²。同一公开组织切片的七个预留视野上，汇总实例 F1 从 0.813 提升到 0.854；未训练新权重，不代表跨患者准确率。修复开发运行库缺少 LZW TIFF 解码组件的问题，并纳入后续 Windows 打包配置。

- 将多标记表型与空间邻域正式接入“荧光 → 测量”的统一任务列表：复用当前图片核分割，按原始 marker 强度分类；结果使用原画布叠加、测量历史与带单位的 CSV。核分割参考参数经验证集选择，提供显式加载入口，不更改已保存结果。

- 图片浏览：选择文件夹按钮独立成行，路径在下方自动换行，避免长路径挤压按钮、导致文字显示不全。适用于中英文界面。
- 全软件整数与小数输入框统一上下调节按钮的箭头、宽度及交互样式，修复通道最小／最大值等位置仍使用细小默认箭头的问题；同步调整风格实验室的局部样式。
- 修复通道菜单动态换行后紧凑页面高度未及时刷新的问题，避免内容被截断、滚动后出现不可用留白。
- 各工作流统一采用少留白侧栏：保留单层外侧边距，去除通道、显示优化、图片浏览与排版属性等嵌套容器的重复横向缩进；同步收紧风格参数区。
- 修复少留白样式使分组标题与首行控件重叠的回归：移除覆盖 Qt 分组框标题留高的通用样式，保留紧凑布局边距。
- 新增合成多通道空间分析 Demo：核分割与可调外扩、marker 阈值表型、ROI 汇总、最近邻与半径邻域及标签置换演示；合成数据不用于真实实验结论。
- 统一空间分析 Demo 的 marker 名称框与阈值框行高；按实验特征重绘八个模块导航图标，取消荧光／图片浏览、IHC／明场之间的重复图标。
- 图片读取不设固定宽高：取消应用内 Qt／Pillow 的通用大图配额；修复单像素宽高图像被误当成可压缩维度的问题。显示预览独立缩放，保留原始像素尺寸。
- 空间 Demo 增加原始四通道 uint16 TIFF 载入，画面、ROI、比例尺与 CSV 跟随原图尺寸和标定；无标定时使用像素单位。邻域改用空间索引，避免密集细胞的全距离矩阵占用。
- 引入论文配套 BBBC039 标注核图、MCMICRO 组织多通道原图和五张 ImageGen 荧光测试图进行验证；测试结果与分割限制见 `docs/SPATIAL_VALIDATION_1.2.3.md`。固定阈值 Demo 尚不代表密集组织的可靠分割或生物学表型准确率。
