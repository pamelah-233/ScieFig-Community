# 1.2.3 空间分析接入核对（2026-11-03）

2026-11-04 补充：正式入口已更名为“荧光 → 测量 → 多标记表型与邻域”（英文 Phenotypes & neighbors），下文旧名称保留作开发记录。真实本地图片已用于流程验证，见 `UPDATES_1.2.3.md`；原文“等待真实图片”描述的是当时状态。当前并未建立本地人工标注准确率。

本轮按用户要求暂停模型及分割参数调优，等待用户真实组织荧光图片。以下是功能接入检查，不是新的准确率评估。

## 对照对象与结论

桌面 `ScieFig 空间分析 Demo.lnk` 指向本项目 `.local-runtime/ScieFig/ScieFig_R10.exe --spatial-demo`。核对 `ui/dialogs/spatial_demo.py`、`core/spatial_demo.py` 与聊天截图中的原始需求。

接入原来存在明显缺口：只有主要计算及两张结果表，缺少完整的画布交互、显示模式、距离分布、邻域组成和分组汇总。本轮沿用荧光测量的侧栏、主画布、固定计算按钮及历史列表补齐，保留独立 Demo 作为参考入口。

正式入口：**Fluoro → Measure → Multi-marker / spatial**（中文：**荧光 → 测量 → 多标记 / 空间邻域**）。

## 功能逐项核对

| 预设能力 | 正式流程位置及行为 |
|---|---|
| 多通道原始数据及标定 | 沿用荧光导入和通道解释；原生尺寸分析，不限定宽高；使用原始强度。无标定使用 px，已标定使用 µm，支持 X/Y 独立比例。RGB 合成图不能冒充独立原始 marker 数据。 |
| DAPI 核分割、弱信号筛选与复核 | 复用“核／对象”任务及已有筛选／复核结果；空间任务选择已保存核分割。参考设置按钮进入原核任务，不自动重新分析。 |
| 核外扩估计细胞 | 可编辑外扩距离，最近核分配保证外扩区域不重复占有；核＋外扩边界可在主画布显示。 |
| marker 名称、通道选择、阳性阈值 | 任意选用可读独立通道，编辑名称和原始强度阈值；按外扩区域的通道均值判断阳性，保留多阳性组合。输入框等高，名称和阈值均可见。 |
| 通道显隐、表型图与原图 | 独立控制核通道和各 marker 显隐；画布模式为表型、原图、核＋细胞边界、邻域聚类；显隐不改变定量。表型图例显示在测量结果旁。 |
| 预设 ROI 与自定义 ROI | 全图／左半／右半／中央区域，以及最新或指定已保存 ROI；测量页可直接绘制矩形／自由形 ROI，画布显示范围边界。 |
| ROI 类型和实验分组 | “ROI 标签／邻域聚类”折叠区填写类型、实验组；随每次测量保存，历史回看恢复。 |
| 数量、密度、各表型占比 | 结果摘要、表型表和 CSV；按 ROI 中核质心计数，尊重来源对象的排除标记。 |
| 任意 A → B 与同类最近邻 | A/B 表型可选；最多 8 个 marker 时列出所有阳性组合（包括本图未出现者），更多 marker 时可输入组合；排除自身，输出最近距离、均值、中位数、距离直方图。无目标时明确为空。 |
| 固定半径邻域 | 可编辑半径，默认 20；输出每个细胞的各表型邻居组成、A 周围 B 数、具有 B 邻居的 A 占比、平均 B 数。 |
| 细胞点击联动 | 主画布点选或结果表点选，显示原始 marker 均值与邻域组成，叠加邻域圆和最近 B 连线。 |
| 空间互作检验 | 保留 Demo 的 199 次条件标签置换与双侧 Monte Carlo p；以当前位置／表型数量为条件，不自动解释为生物学因果。 |
| 探索性 Niche | 可选按邻域表型比例进行 KMeans，显示聚类颜色、细胞归属及每簇平均邻域组成；不把自动簇命名为已鉴定的生物学微环境。 |
| 分组汇总对比 | 结果页“分组对比”：按实验组、ROI 类型、单位及相同分析设置分开，汇总数量、占比、密度、面积、最近邻、邻域数和邻居占比的 ROI 描述均值；同图同 ROI 同设置只用最新记录。保留图像数和 ROI 观测数，不平均 p 值，不假设重叠 ROI 是独立重复。 |
| 完整结果与导出 | 五个结果页签：表型、细胞、邻域、探索性微环境、分组；六份 CSV：摘要、表型、细胞、邻域、Niche、分组，含源核记录、参数、ROI、组别与单位。 |
| 历史、失效与项目保存 | 存入现有 panel.analysis；复用测量历史回看。核来源、ROI、标定或数据来源变化使结果失效，禁止导出陈旧结果。 |

## 保留能力下的 UI 差异

- Demo 的合成图和四通道专用载入器保留在独立入口；正式软件使用统一荧光导入与核复核，允许更多独立通道。
- Demo 的即时重算改为正式测量统一“Calculate”，避免大组织图在每次编辑参数时启动昂贵计算。
- 主画布与同屏结果区联动：宽窗口左右并排，窄窗口上下排列，测量参数仍在原侧栏；同屏显示表型、细胞和邻域表、距离分布与点选详情。保留五页签完整结果窗口和全部 CSV。基础参数直接显示，ROI 标签和聚类参数折叠收纳；其它测量任务隐藏该结果区。
- 画布轮廓、同屏表及完整结果表按同一表型配色，被排除对象为灰色；四 marker 的 16 种组合没有重复颜色。配色表示 marker 阈值表型，不自动推断生物学细胞身份。
- 所有预设分析能力均有正式入口；这不表示核分割、细胞边界估计或 marker 分类已经通过用户真实组织数据验证。

## 本轮验证及边界

使用开发版冻结模块运行离屏 Qt 检查，不需要接管桌面：

- 对同一份 Demo 原始四通道合成数据和相同核掩膜，130 个细胞的 marker 均值、阳性组合一致；多组 A/B（含同类与缺失表型）的距离、置换结果一致。
- 独立逐点距离核对每细胞邻域组成；检查探索聚类、分组去重。
- 正式主窗口完成计算、marker 选项更新、四种画布模式、真实 Qt 鼠标点选、表格联动、绘制 ROI、历史参数恢复、结果陈旧检查、六份 CSV 导出。
- 本地脚本 `.local-runtime/check-spatial-parity.py`；截图和导出 `.local-runtime/spatial-validation/results/parity/`。

修改已写入两个桌面快捷方式实际指向的开发版 EXE。主软件与独立 Demo 均通过实际 EXE 的离屏启动检查，随后从已安装开发版冻结模块重新完成上述功能检查。独立安装版 `D:/ScieFig` 未修改；本次内容积累于 1.2.3，未发布新的 GitHub 安装包。

本轮不训练权重、不运行真实图片调参、不改变既有核参考参数。尚待用户真实组织图片验证弱核、紧密细胞、复杂染色、表型阈值和边缘效应。无全切片流式计算、跨轮次配准或光谱解混的完成声明。
