## ScieFig 1.2.5 for Windows

- 主画布在导入图片或生成图表后自动 Fit，放大超出视口后才可滚动。右栏收放更流畅，图片浏览器可将原图送到 WB 继续处理。
- 荧光可在 RGB 拆分前调整整图黑白点、亮度和对比度。明场和 IHC 可预览、导出调整图，并选择原图或调整后的图像进行分析。
- 简化荧光、明场和 IHC 的测量流程。IHC 可调检测灵敏度，H&E 和 DAPI 的默认模型针对真实样本更新。
- 修复换图时的照度参数报错、逐通道黑白点绑定、跨模块并发导入和计算期间保存的问题。

Windows x64 提供完整版、CPU 基础版和纯英文 CPU 版。CPU 版可加装兼容的 NVIDIA 运行库。[NVIDIA GPU 补充包 / GPU component](https://github.com/pamelah-233/ScieFig-Community/releases/download/community-v1.2.2/ScieFig_GPU_cellpose3_torch212_win64_v1.zip)

> 如果 ScieFig 启动失败、CPU/GPU 显示无连接或功能异常，并且 Windows 提示智能应用控制阻止了组件，请暂时关闭该设置，然后重启 ScieFig。入口为 **Windows 安全中心 → 应用和浏览器控制 → 智能应用控制设置 → 关闭**。
